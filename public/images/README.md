# Local image assets

Replace these placeholder SVGs with your own images, keeping the filenames below:

- `garment-01.svg` — hero and garment 01
- `garment-02.svg` — garment 02
- `garment-03.svg` — garment 03
- `garment-04.svg` — garment 04
- `jamawar-primary.svg` — Jamawar primary image
- `textile-macro.svg` — fabric macro image
- `khaddar-primary.svg` — Khaddar primary image
- `khaddar-macro.svg` — Khaddar macro image
- `boski-primary.svg` — Boski silk primary image
- `cotton-blend-primary.svg` — cotton blend primary image

You can use `.jpg`, `.jpeg`, `.png`, or `.webp`; update the corresponding paths
in `src/utils/image.ts` if you change the extensions or filenames.

The application no longer requests images from Unsplash or generates Unsplash
AVIF/WebP URLs.
